# CodeAlive sample gallery

## Sorting examples

Choose Performance → Bubble vs Quick comparison. Both algorithms receive the exact same list.

| List | Suggested video hook | Expected operation totals: Bubble / Quick |
|---|---|---|
| `8, 3, 6, 1, 9, 2, 5, 4` | Same numbers. Two sorting algorithms. | 41 / 23 |
| `1, 2, 3, 4, 5` | Can Bubble Sort beat this Quick Sort? | 4 / 10 |
| `5, 4, 3, 2, 1` | What does a reversed list sound like? | 20 / 12 |

Totals count comparisons and swaps equally. This is not a speed benchmark. Quick Sort uses a last-element pivot; Bubble Sort exits early on a pass with no swaps.

## Code soundtrack examples

Load these files with CodeAlive: Load Active File, or paste their content into the studio. Choose Code soundtrack mode.

- `javascript.js`: async functions and loops; try Night Drive. Hook: “What does async JavaScript sound like?”
- `python.py`: functions, a class and iteration; try Ambient Cloud. Hook: “My Python code has a soundtrack.”
- `terraform.tf`: infrastructure declarations; try 8-bit Arcade. Hook: “Infrastructure, reimagined as music.”
- `kubernetes.yaml`: a deployment manifest; try Night Drive. Hook: “A Kubernetes manifest, made audible.”

These files are short sonification samples. Some reference placeholder functions or variables. No requirement to execute or deploy them; CodeAlive does neither. Music is inspired by text structure, not actual program execution.

## Recording

Choose 15 or 20 seconds, set your title and captions, and record. Preview outside VS Code after saving. Hide source if desired. MP4 conversion from WebM requires local FFmpeg. Studio recordings do not add narration. For imported narration with code explanations, use [the 0.9 explanation-video workflow](../docs/EXPLANATION_VIDEO.md). YouTube uploading is not included.
